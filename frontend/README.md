# Frontend (React / Vite / ThreeSlicer)

This component owns the responsive browser UI, slicer, profiles and 3D toolpath preview. Run `npm ci && npm test && npm run build` here; `dist/` is served by `../server/ad4_bridge.py` at `/`. Run `npm run dev` only on a trusted development host and start the bridge separately for `/api/printer/*`. Full installation is in [../README.md](../README.md).
